# Rogue Dungeon audio

Every file here is **CC0 (public domain)**: free for any use, including commercial, and no credit is required. Each clip is stored as `.ogg` plus an `.mp3` copy (Safari support), both renamed to the game's cue names. `npm run assets:sync` copies this folder into `public/assets/audio/`.
